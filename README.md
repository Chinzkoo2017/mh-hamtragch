# Эрүүл амьдралын хөтөч — Marine Health бизнес хамтрагч

Marine Health бүтээгдэхүүний танилцуулга, 11-р сарын урамшууллын (2026.11.09–11.30) нэг хуудастай сайт.
Сайт дээр худалдан авалт хийгдэхгүй. «Захиалах» товч бүхэн Marine Health-ийн албан ёсны дэлгүүр рүү лавлах холбоосоор шилжүүлнэ.

- `index.html` — сайт бүхэлдээ (HTML, CSS, JS нэг файлд)
- `images/` — бүтээгдэхүүний нөөц зураг (үндсэн зураг my.marinehealth.asia-аас ачаалагдана)

## Засах
`index.html` доторх `<script>` хэсгийн эхэнд:
- `ORDER_URL` — лавлах холбоос
- `SALE_END` — урамшуулал дуусах огноо
- `DEALS`, `GIFTS`, `PRODUCTS`, `SETS` — урамшуулал, бүтээгдэхүүн, үнэ

Энэ нь Marine Health-ийн албан ёсны вэб сайт биш. Бүтээгдэхүүний зураг: Marine Health.
