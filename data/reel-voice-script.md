## Хэрхэн бичүүлэх

1. ElevenLabs-д мөр бүрийг **тусдаа** файл болгож үүсгэнэ. Нэг мөр = нэг файл.
2. **Zorigoo** = эрэгтэй хоолой, **Alimaa** = эмэгтэй хоолой. Хүснэгтийн «Хоолой» баганыг дагана.
3. «Унших текст» баганыг яг хуулж оруулна. Тоо, брэндийн нэрийг дуудлагаар нь бичсэн (Кардио Марин, Эм-Эс-Эм г.м.).
4. Файлыг **reel-ийн нэртэй хавтсанд, 01, 02, 03… гэж** нэрлэнэ. Жишээ: `assets/voice/cardio/01.mp3`. mp3, wav, m4a аль нь ч болно.
5. Файлуудаа `D:\MyDocs\Projects\mh-hamtragch\assets\voice\` хавтаст хийгээд надад хэлэх, эсвэл GitHub дээр шууд upload хийнэ. Reel-ийн бүх мөр бэлэн болмогц сайт хоолой, аяыг автоматаар нийлүүлж, хэсэг бүрийн уртыг хоолойд тааруулна.
6. Санал болгох тохиргоо: Eleven v3 (эсвэл Multilingual v2), Stability ~45%, Similarity ~80%, Style 20–30%, хурд 1.0–1.05. Өнгө аяс баганыг харж найрсаг, яриа хэлбэрээр уншуулна.

Дэлгэцэн дээрх том бичиг (cap) хоолойтой давхцахгүй, тусдаа харагдана. Сүүлийн мөр бүх reel-д ижил (төгсгөлийн карт).
